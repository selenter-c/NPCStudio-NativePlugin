# NPCStudio 0.8.4 — привязка волос и чтение кэша

- Лог Skyrim 0.8.3 показывает, что в некоторых живых кадрах новые волосы отрисовывались без костей в own-world, тогда как тело оставалось в захваченной позе. Примерка даёт сцене короткое окно на обновление и перед открытием вида проверяет привязку основного меша и дополнительных частей. Если привязка ещё отсутствует, используется исходная поза Phantasm. Для камеры продолжается последний запрос. Движение модели не включается автоматически.
- Готовые миниатюры читаются пачками до 8 напрямую из прежнего HairThumbnails/v1, с сохранением проверки ключа NIF. Дисковый кэш подтверждён на профиле MO2 в overwrite. Кадры из кэша появляются независимо от ожидающего снимка новой причёски. Новые снимки остаются последовательными. После клика по карточке открывается один живой вид вместо двух.
- Проверки: сборка, CTest и имитация UI, включая показ миниатюры из диска при зависшем новом снимке. В Skyrim проверить разные причёски после примерки, повторное открытие каталога и первый проход по ещё не снятым моделям.


# NPCStudio 0.8.3 — быстрое перелистывание причёсок

- Рядом с кнопкой сетки появился ползунок с порядковым номером и общим числом причёсок. Сетка, ползунок и кнопка показывают один выбор. Примерка использует существующий живой вид NPC без запросов миниатюр.
- При быстром перетаскивании промежуточные шаги объединяются. Запрос уходит после паузы 120 мс или сразу при отпускании. Отмена возвращает прежнюю причёску и позицию ползунка. Headless-тест проверяет эти действия на каталоге из 1002 записей.


# NPCStudio 0.8.2 — камера и загрузка миниатюр

- «Внешность», «Мои персонажи» и «Снаряжение» используют один обработчик камеры с ЛКМ, ПКМ, Shift+ПКМ, колёсиком, освещением и сбросом. Во «Внешности» вместо перезапуска таймера при каждом движении используется requestAnimationFrame с одним запросом в работе. Повторные ответы с тем же URL не переназначают src.
- Один тайм-аут больше не отключает IntersectionObserver. Через 4 секунды отменяется только ожидающий снимок с совпадающим токеном. Очередь продолжает показ остальных карточек. Видимая область в приоритете, небольшая зона вокруг неё прогревается заранее.
- Миниатюры 128×128 сохраняются в Data/SKSE/Plugins/NPCStudio/HairThumbnails/v1 по пути и содержимому основного NIF. Повторное открытие использует готовый файл. Отдельная замена текстуры без изменения NIF не инвалидирует снимок. Холодная очередь по-прежнему выполняет по одному снимку Phantasm. В игровом логе 0.8.1 интервал был около 0.7–0.8 секунды.
- Проверено сборкой, CTest и имитацией UI. Тесты покрывают объединение событий камеры, смещение ПКМ, пропавший ответ миниатюры, отмену и получение следующей картинки из кэша. Плавность и скорость в игре проверяет пользователь.


# NPCStudio 0.8.1 — примерка и каталог причёсок

- В «Внешности» живой Phantasm-вид с вращением ЛКМ и масштабом колёсиком. Выбор карточки или цвета меняет только загруженную модель NPC на время примерки. «Применить» записывает изменения в состояние, «Отменить примерку», смена вкладки и закрытие снимают неподтверждённый вариант. В co-save попадают только подтверждённые изменения.
- Каталог берёт совместимые с расой и полом игровые HDPT, включая установленные моды. Поиск по названию и плагину. NIF проверяются по мере использования через VFS Skyrim, с ограничением 16 МиБ на файл. Модели с маркером SMP требуют загруженного hdtSMP64.dll. После исчезновения зависимости при загрузке используется исходная или расовая причёска.
- Сетка в три столбца. Один запрос снимка Phantasm за раз, только видимые карточки, кэш до 512 результатов в UI. Снимок показывает основной NIF причёски, отдельные дополнительные части видны при примерке на NPC. Две служебные MISC (0x802/0x803) в NPCStudio.esp чередуются, поскольку ItemShotStart может переиспользовать геометрию прежнего FormID. ID пула, манифест и формат co-save сохранены.
- Пока сетка открыта, живой рендер приостанавливается, последний кадр остаётся на экране. ItemShotStart в Phantasm 0.3.0 отклоняет запрос при активном live view (view-drawing). После закрытия сетки кадр оживает, старый снимок отменяется.
- Сборка, CTest и Mutagen проходят. Headless UI проверяет примерку и отмену, фильтр плагина, сетку из 1002 записей и ленивый запрос миниатюр. В Skyrim проверить кадрирование, разные NIF подряд (особенно KS Hairdos / SMP), смену цвета, отмену на NPC из мира, co-save после применения и поведение при снятии/удалении зависимости.


# NPCStudio 0.8.0 — первый редактор внешности

- По Shift+8 при наведении открывается «Внешность» NPC под прицелом. Для своего NPC также работает выбор в общем списке. Редактор применяет причёску и цвет одним действием. Палитра берётся из расы и пола NPC, список причёсок из совместимых записей Skyrim и DLC. Поддержка модовых причёсок, SMP и произвольного RGB отложена.
- Свои NPC: замена на загруженной модели, запись в отдельную базу слота и сохранение ключей HDPT/CLFM в co-save. При смене расы настройка сбрасывается. Прежняя структура co-save пула читается.
- Мир: только уникальные взрослые живые NPC со стабильной ссылкой и загруженной головой вне боя. Меняется модель конкретного актёра, NPC_ и FaceGen на диске не затрагиваются. В co-save сохраняются ссылка и ожидаемая база с ResolveFormID, волосы/цвет по plugin + local ID. Повторное применение на новой голове проверяется игровым потоком примерно раз в 600 мс, максимум 128 NPC на сохранение. Для замены должен быть доступен распознаваемый узел волос. Моды, которые сами меняют голову или перекрашивают её, требуют отдельной проверки.
- Исследование: SKSE PapyrusActor.cpp / InternalTasks.cpp разделяют запись в TESNPC и замену на модели. Публичный RaceMenu ищет узел по имени части и сохраняет цвет отдельно. Rizin-анализ локального NPA.dll показал SetRecordHair, обработчики Try/Color/Done и вызов RaceMenu.SaveHair для игрока. Это наблюдение по бинарю, не подтверждение его полного алгоритма. Код NPA не использован.
- Проверка в Skyrim вручную: свой NPC и уникальный NPC из мира без шлема, смена волос и цвета, затем переход между локациями, сохранение и полный перезапуск. Для своего NPC дополнительно сменить расу и проверить, что старые волосы и цвет не возвращаются. В бою и на неподдерживаемом актёре редактор должен сообщать о недоступности.


# NPCStudio 0.7.3 — управление инвентарём

- «Снаряжение → Инвентарь» применяет выбранный набор к активному NPC. Старое снаряжение снимается, вещи остаются в инвентаре. Повторно используются уже имеющиеся экземпляры, выдаётся только недостающее количество.

- Проверки: build.bat, CTest 2/2, Mutagen 400 слотов, headless UI с имитацией игрового API. В Skyrim проверить замену между наборами с разными слотами, снятие оружия в обеих руках, удаление надетого предмета или стопки и сохранение результата после загрузки.

Портрет: обнаружен CSS max-height520 на viewport, несмотря на height640 в редакторе. Круг/сохранение считались по640. Добавлен max-height:none; регрессия проверяет480x640. # NPCStudio 0.7.0 — сборка для игрового теста

Пользователь подтвердил: портреты 0.6.9 сохраняются, остальные прошлые проблемы (включая голову после полного перезапуска) исправлены. Стабильность 0.7.0 в Skyrim пока не проверена.

Изменения 0.7.0:
- Исправлен RequestPreview(capture): обновление живой модели больше не удаляет Portraits. Убраны сбросы кэша при открытии меню и смене снаряжения. Явная пересъёмка обновляет изображение.
- portraitCache читает сохранённые .image пачками до24 по identity активных назначений, без Initialize/Phantasm и проверки Is3DLoaded. UI сначала загружает дисковый кэш, затем генерирует только отсутствующие; память до400 портретов. Отмена запроса при смене вкладки разрешает повторную попытку.
- Сохранены standalone framing2 и crop-компенсация 0.6.9. Новое сохранение портрета по-прежнему требует GPU-снимок, ускорена именно загрузка уже сохранённых.
- Портретный редактор, кнопки и UI scale используют T и ru/en, обновляются при смене языка.
- Каталог: Все (ARMO/WEAP/AMMO), дополнительные категории по слоту брони/оружию/боеприпасам. SVG-иконки перед названиями в каталоге/инвентаре. Прочие типы записей ещё не поддерживаются.
- Удалены неиспользуемые старые модули PrismaUI/NPCFactory/заглушки appearance,bio,preset,naming,input и Game Legacy0.1.0. Перечень docs/CLEANUP_070.md. Собственный NIF viewer сохранён, хотя не включён в текущую сборку. stb_image_write используется ActorPreview.

Проверки: build.bat (CTest2, Mutagen400слотов, упаковка64файла); Chrome mock regression: вкладки/refresh сохраняют аватар, diskcache не делает GPU capture, ru/en редактора, фильтр категории и иконки, существующие CRUD/camera/slots/equipment/settings на720p/1080p. Скриншоты ui-070 — имитация игрового API, не Skyrim.

Установка: NPCStudio-Build/dist/NPCStudio-0.7.0-fomod.zip. Сохранить пользовательские settings.json, Equipment/user-*.json, categories.json, Portraits/*.image при замене установленного мода. MO2/Skyrim не запускать автоматически. Computer use запрещён пользователем.
