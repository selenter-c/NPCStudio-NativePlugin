# NPCStudio 0.6.5
Пользователь подтвердил исправление головы при полном перезапуске, паузы и портретного readback в0.6.4. Остаётся проблема pan: CSS translate перемещает всю текстуру вместе с фоном; настоящий pan Phantasm ещё не реализован. Не считать этот пункт исправленным.
Новые изменения: портреты сохраняются атомарно в Data/SKSE/Plugins/NPCStudio/Portraits/<identity>.image (PNG data URI); identity содержит слот, время создания и процесс, не зависит от переименования. Удаление/повторное использование слота получает новую identity. MO2 направит runtime-файлы в Overwrite/назначенный output; сохранить их при обновлении. Для портрета открывается dialog с круглым crop256, drag/zoom, Save/Cancel. Сохранение идёт через проверку id/identity в StudioService. Существующий портрет загружается с диска вместо повторного рендера. Кэш пока считывается только для загруженного NPC (ограничение Frame проверки). Файл не распространяется с ZIP.
Настройки на полную ширину; scale .6..1 хранится в settings.json, центрированное уменьшение окна; новый векторный знак. Версия0.6.5. Build/CTest2/Mutagen/ZIP и UI smoke прошли, новые игровые изменения ждут пользовательского теста. Продолжить с настоящим camera pan; нельзя считать CSS перенос реализацией 3D смещения. Сохранения старых версий не мигрируем. Реальный запуск выполняет пользователь.
