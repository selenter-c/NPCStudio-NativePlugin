# NPCStudio 0.7.2 — библиотека наборов и управление

- Новый presets.js: редактор наборов без NPC, создание/копирование, каталог, количество 1..1000, до 64 предметов. Сохранение надетого удалено. Встроенные наборы только читаются; изменять можно собственную копию. Native проверяет user- идентификатор, адреса, дубликаты, количества, пишет атомарно.
- Library возвращает названия/категории предметов и custom; состав виден при создании NPC и в библиотеке. Удаление встроенных наборов отключено и защищено backend. Категорию нельзя удалить, пока в ней есть наборы; подпись «Удалить категорию».
- Прогресс резервов, красные danger-кнопки, активная вкладка снаряжения. Ember по умолчанию для новой конфигурации (существующий выбор не перетирается). Закрытие тем же chord обрабатывается также DOM, поскольку Magelight захватывает клавиатуру.
- Удалён src/nifviewer и устаревший архитектурный документ. Единственная используемая часть stb_image_write.h перенесена в src/thirdparty с лицензией.
- RE Phantasm 0.3.0: FUN1800586f0 ограничивает физический масштаб 0.45..2.6 (float RVA22983c/2298f8). Ранее использовали .5.. .95, теперь весь диапазон; запрос 4× в обе стороны НЕ полностью достижим текущим API. CameraScale(.25)=2.6, CameraScale(1)=.8375, CameraScale(4)=.45. При scale>=1 anchored pan провайдера сбрасывается; crop учитывает это.
- FUN180021a90 распознаёт weapons=on/true/1. Live и still явно включают weapons. Фактическую видимость оружия подтверждает только тест в Skyrim.
- Headless UI: CRUD, добавление предмета/количества, защита встроенного набора, chord close, портреты/камеры/локализация/720p/1080p. CTest проверяет новые границы CameraScale. Сборка через build.bat, игра автоматически не запускалась.

Ручной тест: готовый набор → копия → добавить/убрать предмет → сохранить → создать NPC с набором; Shift+8 закрывает; колёсико до обоих пределов; переснять портрет NPC с экипированным оружием. Старые портреты остаются в кэше — для проверки оружия переснять.
