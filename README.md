# NPCStudio 0.3.1 — удаление и совместимость имён

Skyrim 1.6.1170, SKSE, Address Library, Magelight UI 1.5.0+. F8 открывает окно в мире с закрытыми меню и консолью.

Собственный постоянный пул 80+80: создание, имя, призыв, скрытие, переход к NPC. Назначения сохраняются в SKSE co-save. Базовая работа подтверждена пользователем в игре на 0.2; точные шаги save/restart/load отдельно не зафиксированы.

0.3 добавляет инвентарь, поиск одежды/брони/оружия/боеприпасов из загруженных модов, выдачу и надевание, снятие, 16 готовых наборов и сохранение надетого в пользовательские наборы. При применении набора прежние вещи остаются в инвентаре; повторное применение довыдаёт недостающее до указанного количества. Все действия выполняются через Magelight PostGameTask на игровом потоке, только для собственных занятых слотов. Для изменения снаряжения нужен живой загруженный NPC.

Наборы: Data/SKSE/Plugins/NPCStudio/Equipment/*.json, schemaVersion=1, name, items[{plugin,form,count}]. form — числовой локальный FormID, не runtime ID. Пользовательские файлы user-*.json общие для сохранений, записываются через VFS MO2 (проверяйте также overwrite). Переносятся базовые формы, без пользовательского зачарования, улучшения и выбора руки. Набор одежды не меняет фракцию, ИИ, боевой стиль или профессию NPC.

Сборка: соседний NPCStudio-Build/build.bat. Pinned alandtse/CommonLibVR, MSVC v143 14.44, static CRT. Старые подсистемы не входят в CMake target. Внешность, 3D-превью и SkyrimNet ещё не подключены; FaceGen отложен по просьбе пользователя.

Проверки 0.3: сборка, CTest StateCodec, ESP Mutagen, упаковка, браузерный UI smoke с mock bridge. Снаряжение подтверждено пользователем; новые функции 0.3.1 ожидают игровой проверки. Computer-use запрещён; все игровые действия выполняет пользователь.

## Изменения 0.3.1

Кнопка удаления рядом с выбранным NPC открывает подтверждение. Удаляются инвентарь и запись личности NPCStudio, прекращается бой, сбрасываются повреждения основных ресурсов, актёр отключается и перемещается к постоянному XMarker 000801 в резервной ячейке. После проверки очистки слот освобождается; при новом создании получает новую identity. Это не MarkForDelete: зарезервированные ActorBase/reference сохраняются. Глобальные пользовательские наборы не удаляются. В текущей версии данные NPCStudio — имя и identity; подсистемы внешности/биографии ещё не подключены. Состояние сторонних квестов, отношений и баз данных других модов этим не стирается.

NPCs Names Distributor: собственные персонажи помечаются NNDUnique/NNDKnown через SPID и runtime-keywords. Публичный NND API v1 RevealName снимает уже сохранённую Obscurity при загрузке/создании/переименовании; full/short/display name устанавливаются вместе, прицел обновляется UI task. Без NND работа сохраняется, новая обязательная зависимость не добавлена. Общие настройки NND/Tamrielic Names и другие NPC не меняются. Требуется полный перезапуск Skyrim, чтобы SPID прочитал новый INI.

include/NND_API.h взят из adya/NPCs-Names-Distributor, commit 2986a406f8e07ae3c95e20614c58b115ad1b4c64, GPL-3.0 (NND-LICENSE.txt). Исправлен upstream helper GetModuleHandle на явный GetModuleHandleW с wide literal. Обёртка NameCompatibility сама использует явные WinAPI-вызовы; ABI интерфейса не менялся.

0.3 подтверждена пользователем в игре (включая снаряжение); лицо исправилось после настройки модов. Удаление/совместимость 0.3.1 прошли сборку и mock UI, но требуют ручной проверки в игре, в том числе на сохранении 0.3 с уже скрытым NND именем.
