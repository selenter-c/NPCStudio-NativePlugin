# NPCStudio 0.3 — снаряжение

Skyrim 1.6.1170, SKSE, Address Library, Magelight UI 1.5.0+. F8 открывает окно в мире с закрытыми меню и консолью.

Собственный постоянный пул 80+80: создание, имя, призыв, скрытие, переход к NPC. Назначения сохраняются в SKSE co-save. Базовая работа подтверждена пользователем в игре на 0.2; точные шаги save/restart/load отдельно не зафиксированы.

0.3 добавляет инвентарь, поиск одежды/брони/оружия/боеприпасов из загруженных модов, выдачу и надевание, снятие, 16 готовых наборов и сохранение надетого в пользовательские наборы. При применении набора прежние вещи остаются в инвентаре; повторное применение довыдаёт недостающее до указанного количества. Все действия выполняются через Magelight PostGameTask на игровом потоке, только для собственных занятых слотов. Для изменения снаряжения нужен живой загруженный NPC.

Наборы: Data/SKSE/Plugins/NPCStudio/Equipment/*.json, schemaVersion=1, name, items[{plugin,form,count}]. form — числовой локальный FormID, не runtime ID. Пользовательские файлы user-*.json общие для сохранений, записываются через VFS MO2 (проверяйте также overwrite). Переносятся базовые формы, без пользовательского зачарования, улучшения и выбора руки. Набор одежды не меняет фракцию, ИИ, боевой стиль или профессию NPC.

Сборка: соседний NPCStudio-Build/build.bat. Pinned alandtse/CommonLibVR, MSVC v143 14.44, static CRT. Старые подсистемы не входят в CMake target. Внешность, 3D-превью и SkyrimNet ещё не подключены; FaceGen отложен по просьбе пользователя.

Проверки 0.3: сборка, CTest StateCodec, ESP Mutagen, упаковка, браузерный UI smoke с mock bridge. Игровая проверка нового снаряжения ожидается. Computer-use запрещён; все игровые действия выполняет пользователь.
