# NPCStudio 0.5.0

Skyrim 1.6.1170 · SKSE · Address Library · Magelight UI 1.5+. Открытие **Shift + 8** (верхний цифровой ряд). Своё сочетание Shift/Ctrl/Alt можно сохранить в настройках. Старый стандартный Shift+F8 мигрирует, пользовательские назначения сохраняются.

## Новое

- English и Русский. При первом запуске язык интерфейса Windows определяет выбор: русский либо английский для остальных систем. Выбранный язык сохраняется в settings.json и больше не зависит от Windows. Названия пользовательских NPC, категорий и игровых предметов не переводятся.
- Четыре палитры: аметист, изумруд, сапфир, тлеющий янтарь. Новый знак студии, явные точки SVG-кубика, «Не выбран» в списке NPC, случайные полезные подсказки при открытии. Сообщения операций временные; лишняя подпись подключения убрана.
- Выбор одной из десяти стандартных рас при создании и смена расы существующего NPC. Штатный Actor.SetRace вызывается через Papyrus VM; завершение отслеживается callback и фактической расой/3D. Инвентарь снимается до изменения, затем экипировка восстанавливается. На время перестройки мутации блокируются. Новые поля расы сохраняются в co-save; FormID слотов и ESP не меняются. Пользовательские расы пока не включены.
- Экспериментальное 3D-превью загруженного NPC: поворот мышью/ползунком, масштаб, студийный/тёплый/холодный свет, обновление модели. Портреты вместо букв создаются постепенно для первых 24 NPC отфильтрованного списка. У незагруженного NPC — силуэт; можно призвать персонажа и обновить превью. Изображения временные, в co-save не пишутся.

## Рендер: границы текущей версии

Это собственный рендер, а не подключение закрытого DLL SeverActions. API SeverActions не экспортирует рендер. Подробный разбор доступного контракта: docs/RENDERING_050.md.

Захватывается текущая поза загруженной модели, включая одежду и доступную геометрию головы. Последующие повороты рисуют этот снимок; анимации не проигрываются. После внешнего изменения одежды/внешности нажмите обновление. Диффузные текстуры и базовые tint используются, но FaceTint/макияж, normal/SSS/ENB/Community Shaders и прозрачные материалы не воспроизводят весь игровой шейдер. Неподдержанные части пропускаются с показом количества и записью в лог. Первое чтение GPU-буферов может дать краткую задержку.

Игровой NPC не перемещается ради превью. Native команды выполняются через Magelight PostGameTask на игровом потоке; GPU использует устройство Skyrim и deferred context с восстановлением состояния. В страницу передаётся PNG, без второго D3D-устройства и без перехвата камеры.

## Основа 0.4

Пул 200 женских + 200 мужских persistent NPC. Создание со свободным слотом и обмундированием; автоматический выбор предпочитает новые слоты, затем неизвестные старые, затем использованные. Имя, призыв/скрытие/переход, удаление с очисткой собственных данных и вещей. Чужие квесты/отношения/AI-базы удаление не очищает.

40 готовых комплектов, свои категории, сохранение надетых базовых предметов; каталог загруженных модов. Наборы не меняют фракции/ИИ, не клонируют custom enchant/temper. Перед скрытием и при сохранении активного NPC записываются вещи/надетое, после возврата выполняется повторное надевание существующих вещей и проверка количества. Автодовыдачи при проверке нет. Динамические FF-формы пропускаются. Старый скрытый NPC из 0.3 без снимка требует однократного применения комплекта.

Tamrielic Names/NND, включая установленный русский перевод, читаются через MO2 VFS; исходные списки не перераспространяются. Выбирается базовое имя по полу и расе, без полного алгоритма фамилий/титулов NND. RevealName и SPID исключения обеспечивают немедленную видимость заданного имени.

Полный редактор головы/RaceMenu и SkyrimNet-биографии ещё не подключены.

## Обновление и проверки

0.4 подтверждена пользователем в Skyrim: checkpoint-0.4.0-user-tested. 0.5 — экспериментальная сборочная точка, ещё требует игрового теста рендера и смены рас. Не путать mock-скриншоты docs/ui-050-*.png с кадрами Skyrim.

Сделайте отдельный сейв перед обновлением. Установите ZIP целиком при закрытой игре. Сохраните Equipment/user-*.json, categories.json, settings.json, в том числе MO2 overwrite. Все DLL/UI/ESP/slots.json обновлять вместе. Пул poolVersion2 читает старую version1; для отката используйте сохранение до обновления.

Сборка: соседний NPCStudio-Build/build.bat, обычно инкрементально. Pinned alandtse/CommonLibVR ng, MSVC14.44, static CRT. CTest: co-save/настройки/миграции; Direct3D WARP: компиляция HLSL, PNG кадров, изменение камеры/света, восстановление viewport. Mock Chrome: две локали, палитра, расы, портреты, камера, базовые операции, 5 страниц 720p/1080p. Mutagen проверяет 400 слотов, pack — DLL/source hashes, версию и ZIP. Это не заменяет ручной игровой тест. Установку и запуск выполняет пользователь.

NND_API.h: adya/NPCs-Names-Distributor, GPL-3.0 (include/NND-LICENSE.txt), helper GetModuleHandleW исправлен без изменения ABI. Magelight API: include/Magelight-LICENSE.txt. stb_image_write сохранён с исходным уведомлением лицензии.
