# NPCStudio 0.6.0 — тестовая сборка

Skyrim 1.6.1170, SKSE, Address Library, Magelight UI 1.5+ и проверенный **Phantasm 0.3.0 ccf916f72d59** из предоставленного SeverActions4.7.0. Открытие **Shift + 8** (верхний цифровой ряд); Esc закрывает меню. Язык ru/en, палитра и сочетание сохраняются в настройках.

В0.6.0 экспериментальный собственный D3D-renderer заменён клиентом экспортированного Phantasm API: живой NPC,6 вариантов света, поворот/zoom, отдельные аватары и кнопки3D для предметов инвентаря/каталога. Нет чтения GPU/PNG и полного Snapshot на каждом повороте. Закрытие и смена вида освобождают клиент; устаревшие callbacks отбрасываются. Подробный разбор и ограничения: [docs/RENDERING_060.md](docs/RENDERING_060.md).

Установите в MO2 два локальных архива из соседнего NPCStudio-Build/dist: NPCStudio-Phantasm-0.3.0-local.zip и NPCStudio-0.6.0-fomod.zip. Не включайте другой Phantasm.dll поверх проверенной версии. Полный SeverActions для адаптера не требуется. Перед обновлением закройте игру; свои Equipment/user-*.json/categories.json/settings.json сохраните. Установку/запуск выполняет пользователь; computer-use не используется.

Пул400:200 женских +200 мужских, только текущие схемы manifest3/co-save record2/poolVersion3. Миграций прежних сохранений нет, тестирование с новой игры. Автоматически выбираются новые слоты; история освобождённых слотов сохраняется. Создание с расой и комплектом, редактирование расы через CommonLib SwitchRace, сохранение/возврат одежды,40 встроенных наборов, свои категории и наборы, Tamrielic/NND имена сохраняются.

Сборка: соседний NPCStudio-Build/build.bat, инкрементально, MSVC14.44/staticCRT, pinned alandtse/CommonLibVR. CTest проверяет state/settings и контракт камеры/ABI, Chrome — mock UI. Производительность и отсутствие вылетов в Skyrim0.6.0 ещё требуют ручного теста; автоматические проверки это не доказывают. Полный редактор головы/RaceMenu и SkyrimNet пока не подключены.

NND_API.h: GPL-3.0, include/NND-LICENSE.txt. Magelight API: include/Magelight-LICENSE.txt. Уведомление лицензии stb_image_write сохранено в header. Чужие бинарники/декомпилированный код не публикуются в Git.
