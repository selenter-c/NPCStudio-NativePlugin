# NPCStudio 0.7.0

Единая студия постоянных NPC для Skyrim SE 1.6.1170. Интерфейс Magelight UI, открытие Shift + 8; сочетание, язык ru/en, палитра и масштаб настраиваются в меню.

Работает: 200 женских и 200 мужских слотов, создание с расой/именем/комплектом, призыв/скрытие/очистка слота, каталог и наборы экипировки, живое 3D-превью NPC и предметов, редактор круга портрета с сохранением на диск. Изменение внешности через RaceMenu и генерация биографий SkyrimNet — следующие этапы.

Локальный установщик: `../NPCStudio-Build/dist/NPCStudio-0.7.0-fomod.zip`. Требуются SKSE, Address Library, Magelight UI. Проверенный Phantasm и его ресурсы включаются в один локальный архив; чужие бинарники в Git не публикуются. Сборка через `../NPCStudio-Build/build.bat`.

При обновлении сохраните пользовательские `Data/SKSE/Plugins/NPCStudio/settings.json`, `Equipment/user-*.json`, `categories.json` и `Portraits/*.image`. Персонажи сохраняются с игрой и SKSE co-save. Миграции старых схем тестового проекта не поддерживаются.

0.7.0 ускоряет чтение сохранённых портретов без запуска рендера, исправляет потерю аватара при смене вкладок, локализует редактор портрета, добавляет иконки и категории предметов. Старые неиспользуемые PrismaUI-модули и заглушки удалены. Детали — `../NPCStudio-NativePlugin/docs/STATE.md` и `CLEANUP_070.md`.

Сборка/CTest/проверка ESP/архива и headless UI regression проходят. Проверку нового поведения внутри Skyrim выполняет пользователь; автоматизация игру и MO2 не запускает.
