# NPCStudio 0.2 — основа переработки

Skyrim 1.6.1170, SKSE, Address Library, Magelight UI 1.5.0+.

F8 открывает окно в игровом мире с закрытыми меню и консолью. Доступны создание NPC в собственном пуле 80+80, переименование, призыв, скрытие без освобождения слота и переход к персонажу. Назначения сохраняются в SKSE co-save.

Внешность, экипировка, пресеты, биография и 3D-превью ещё не подключены. Старые файлы этих подсистем сохранены для справки, но не входят в CMake target.

Сборка: ../NPCStudio-Build/build.bat. Используются pinned alandtse/CommonLibVR, MSVC v143 14.44 и статическая CRT. Один раз после смены старого toolchain может потребоваться build-native.ps1 -Fresh; он сбрасывает только конфигурацию CMake.

Проверено: сборка DLL, CTest StateCodec, браузерный UI smoke с mock bridge, генерация/повторное чтение ESP через Mutagen, упаковка. Игра загрузила DLL, 160 слотов и Magelight view. Спавн и постоянство после save/restart/load ожидают ручной проверки. Эта контрольная точка не помечена как стабильный игровой релиз.

Дальнейшее состояние и ограничения: docs/STATE.md и docs/TECHNICAL_AUDIT.md. Пользователь запретил computer-use, все игровые действия выполняет вручную.
