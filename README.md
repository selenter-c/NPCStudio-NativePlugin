# NPCStudio 0.4

Skyrim 1.6.1170, SKSE, Address Library, Magelight UI 1.5+. Открытие по умолчанию **Shift + F8**; изменить основную клавишу и Shift/Ctrl/Alt можно в настройках. Esc закрывает окно. Настройки в Data/SKSE/Plugins/NPCStudio/settings.json общие для сохранений.

## Что доступно

- Пул **200 женских + 200 мужских** persistent NPC, создание с выбором слота и комплекта, имя, призыв, скрытие, переход к NPC, удаление/освобождение слота.
- Автоматический выбор предпочитает новые слоты, затем слоты с неизвестной историей, затем использованные. История хранит только факт использования, не имя удалённого NPC. Занятые слоты выбрать нельзя.
- Инвентарь, каталог из загруженных модов, выдача/надевание/снятие; 40 готовых наборов в категориях. Свои категории и сохранение надетого в переносимый набор. Наборы не меняют фракции, профессию или ИИ.
- Случайное базовое имя из установленного Tamrielic Names/NND, включая русский перевод через MO2 VFS. Для стандартного пула используются NNDNord.json (Middle) и NNDBosmer.json (First), с учётом пола. Без списков — небольшой встроенный запас имён. Полный алгоритм NND для фамилий/титулов/наследования не воспроизводится; исходные списки не перераспространяются.
- NNDKnown/NNDUnique + публичный NND API RevealName сохраняют заданное имя видимым до знакомства; остальные NPC и общие настройки NND не меняются.
- Компактные отдельные страницы создания, списка, снаряжения, библиотеки и настроек; SVG-иконки, собственные combo с поиском и клавиатурой.

## Снаряжение после возврата

Перед скрытием и при сохранении активного NPC записываются количество вещей и надетое. Призыв и загрузка сохранения ставят отложенную задачу: дождаться 3D, надеть существующие вещи, повторно проверить через ~600 мс. Повторная выдача не выполняется, чтобы не создавать копии. В интерфейсе/логе показываются недостающие и не надетые вещи. Динамические FF-формы не входят в переносимую проверку; extras инвентаря остаются у движка. Для скрытого ещё на 0.3 персонажа без снимка прежний наряд достоверно неизвестен: примените комплект один раз.

Pacer jthread раз в 150 мс лишь ставит coalesced SKSE task при наличии работы. Вся работа с RE идёт на игровом потоке, задачи защищены worldEpoch/identity, попытки ограничены шестью секундами. PostGameTask Magelight используется для команд страницы и переключения окна. Свой input sink нужен для модификаторов; Global BindHotkey Magelight больше не используется.

## Обновление с 0.3

Старые 480 записей NPC_/ACHR/CLFM побайтово неизменны. Новые слоты добавлены на свободных адресах, без перенумерации существующих. DLL/UI/ESP/slots.json надо обновлять вместе. Co-save poolVersion=2 читает старую version=1. До 0.4 удаления не записывали историю: свободные старые слоты помечаются «история неизвестна», новые — «новый». Откат на 0.3 требует сохранение, сделанное до обновления: старый DLL не читает poolVersion2.

Удаление очищает инвентарь и запись NPCStudio, прекращает бой, сбрасывает повреждение основных ресурсов, отключает и возвращает reference в резерв. Сторонние квесты, отношения и AI/SkyrimNet базы не удаляются; пользовательские наборы общие и сохраняются. Appearance/3D preview/SkyrimNet ещё не подключены.

## Файлы и сборка

Equipment/*.json: schemaVersion1, name, category, items[{plugin,form,count}]; form — локальный числовой ID. Категории: categories.json. Пользовательские user-*.json, categories.json и settings.json записываются через VFS MO2 и могут оказаться в overwrite. Сохраняйте их при переустановке.

Сборка — соседний NPCStudio-Build/build.bat. Pinned alandtse/CommonLibVR, MSVC14.44, static CRT. Проверки: CTest миграции/истории/границ, Mutagen, побайтовое сравнение старых records, все ссылки 40 наборов по HouseCarl, ZIP и mock UI в Chrome на720p/1080p. Новые функции 0.4 требуют ручной проверки в Skyrim; это сборочная контрольная точка. Computer-use и автозапуск запрещены пользователем.
