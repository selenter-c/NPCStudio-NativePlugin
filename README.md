# NPCStudio 0.5.1 — тестовая сборка

Skyrim 1.6.1170, SKSE, Address Library, Magelight UI 1.5+. Открытие **Shift + 8** (верхний цифровой ряд), Esc закрывает окно. Клавишу/Shift/Ctrl/Alt, язык и палитру можно сохранить в настройках.

## Политика тестирования

Поддержка старых сохранений NPCStudio и миграции удалены по просьбе пользователя. Для0.5.1 нужна **новая игра**, созданная после установки нового ESP/DLL/UI. Загрузка старого сейва не конвертирует данные и блокируется. Сохранение и загрузка внутри текущей схемы работают как обычно. Пользовательские наборы, категории и настройки — отдельные JSON; они не зависят от расположения слотов.

## Исправления0.5.1

- Единый последовательный пул: id0..199 женские1..200, id200..399 мужские1..200. Старого блока80+80 и раздельно добавленных слотов больше нет.
- История только «новый»/«использовался». Автоматический выбор сначала занимает новый слот. Удаление внутри текущей игры сохраняет факт использования, чтобы не переиспользовать reference без необходимости. Статус неизвестной истории убран вместе с миграциями.
- Создание и смена расы больше не вызывают Actor.SetRace через VM. В0.5.0 этот вызов отклонялся (подтверждено логом). Используется прямой CommonLib Actor::SwitchRace(race,false), Address Library AE37925, на игровом потоке.
- При создании сначала MoveTo/Enable и ожидание3D, затем SwitchRace. Проверяется фактическая раса, повторная загрузка3D и задержка стабилизации перед экипировкой. При редактировании заранее снимается снимок вещей. Нет ожидания Papyrus callback, которое могло блокировать слот без конца.
- Прямое изменение расы требует проверки в Skyrim: сборка доказывает корректность C++/линковки, не игрового поведения.

## Возможности

Пул200+200 persistent NPC, имя/раса/выбор слота/обмундирование при создании; призыв, скрытие, переход, удаление. Десять стандартных взрослых рас, включая OrcRace. Пользовательские модовые расы пока не добавлены.

40 готовых наборов, категории и свои наборы из надетых базовых предметов. Каталог из загруженных модов, выдача/надевание/снятие. Наборы не меняют фракции/ИИ и не клонируют temper/custom enchant. После скрытия/возврата проверяется сохранённое количество вещей и надетое, без автоматической довыдачи; динамические FF-формы пропускаются в переносимом аудите.

Tamrielic Names/NND читается через VFS MO2, включая установленный перевод; выбирается базовое имя по полу/расе. RevealName и SPID исключения сохраняют видимость заданного имени. Исходные списки имён не перераспространяются.

English/Русский: первый выбор по языку интерфейса Windows, далее сохраняется независимо от системы. Четыре палитры, SVG-иконки, combo с поиском, отдельный roster, случайные советы и временные уведомления.

Экспериментальное3D-превью загруженного NPC, вращение/масштаб/три варианта света/портреты. Это снимок текущей позы без анимаций; после смены одежды нажмите refresh. Портреты первых24 NPC отфильтрованного списка формируются постепенно. Для незагруженной модели — силуэт, без телепортации ради изображения.

Рендер собственный, не закрытый код SeverActions. Простые diffuse/tint/alpha-test и geometric lighting не воспроизводят полностью FaceTint, makeup, normal/SSS/ENB/CS/прозрачность. Capture может дать краткую задержку. Подробности: docs/RENDERING_050.md. Полный редактор головы/RaceMenu и SkyrimNet пока не подключены.

## Схемы и сборка

Manifest schema3. ESP:400 NPC/ACHR/CLFM, CELL800/XMarker801. CLFM900+id, NPCB00+id, ACHRD00+id. Всего1202 формы800..E8F, ESL. Co-save recordversion2, JSONpoolVersion3 — только текущая схема, без импорта прошлых.

Соседний Build/build.bat, обычно инкрементально. Pinned alandtse/CommonLibVR ng, MSVC14.44/staticCRT. CTest: текущие co-save/settings, границы/история/отказ от прежних схем; WARP: HLSL/PNG/camera/light/viewport restore. Mutagen проверяет ESP; pack — DLL/source hashes и ZIP. Chrome mock проверяет UI/слоты/выборOrcRace/прочие операции, не реальный SwitchRace. docs/ui-051-*.png — mock, не Skyrim.

Перед обновлением закрыть игру и заменить мод целиком; сохранить user-*.json/categories.json/settings.json и MO2 overwrite. Установку/запуск выполняет пользователь, computer-use запрещён.

NND_API.h: adya/NPCs-Names-Distributor, GPL-3.0, include/NND-LICENSE.txt. Magelight API: include/Magelight-LICENSE.txt. Уведомление лицензии stb_image_write сохранено в исходном header.
